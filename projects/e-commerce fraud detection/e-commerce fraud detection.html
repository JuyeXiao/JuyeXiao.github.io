历史欺诈中，52.23% 属于早期的极短间隔购买子群。分析比较模型对不同行为与时期的识别能力，并据此提出人工审核优先级和三档处理建议。

摘要

本项目分析电商首单中的欺诈行为特征，比较模型的识别能力，并讨论如何分配审核资源与处理不同风险的订单。数据含 138,376 笔交易、1,415 个欺诈标签，整体欺诈占比 1.02%。其中 739 笔注册后不超过一秒的购买全部带欺诈标签，占全部欺诈的 52.23%，集中在 2015 年一月早期。

模型对这种历史子群的识别与对其余交易的识别存在明显差异：拟合集随机诊断 AP=0.635206，排除一秒子群后为 0.006314。时间评估用于检查模式的适用范围。前向验证选中类别权重 LightGBM，冻结时间测试 AP=0.010121、ROC-AUC=0.595995；普通 SMOTE 没有在本次交叉验证或测试集中提供优于无 SMOTE 的 AP。

决策分析显示，排序分数和业务操作需要分别设计。既定成本情景在选择集上选择全批准。测试集的 131 个欺诈均未检出，FP=0，情景成本 $6,876。基于行为发现和这一取舍，报告提出按分数安排人工审核、结合交易线索分为低／中／高风险处理的实施方案。

首单欺诈的分析目标

题目设定电商在新用户首单提交后、发货前判断风险。风险团队既要发现可疑交易，也要控制正常订单的处理负担。分析围绕三个问题展开：欺诈集中在哪些行为子群；不同不平衡处理方法能够识别哪些样本；模型分数如何辅助审核与订单处理。

输入包括已记录的注册与购买时间、金额、账户属性、渠道、浏览器，以及更早发生的设备和 IP 交易事件。class 是文件中的二元欺诈标签。每行对应一个已记录用户的交易，用户 ID 唯一；文件无法确认跨账户身份或业务中的“真实首单”。

当前实验采用回顾性时间评估，在明确费用情景下比较批准与拒绝策略，并结合行为发现提出人工审核及三档处理方案。

交易与标签来源

交易数据包含 138,376 行、11 列，IP 区间表包含 138,846 行。分析围绕首单场景展开，时间字段采用 GMT，金额单位为美元。

交易购买时间为 2015-01-01 至 2015-12-16，注册时间截至 2015-08-18。字段覆盖用户 ID、两类时间、金额、设备、渠道、浏览器、性别、年龄、数值 IP 和标签。缺失值、重复行、重复用户 ID 均为零；金额范围 $9–154，年龄范围 18–76。目标值仅为零和一，时间解析成功且购买不早于注册。原文件未按购买时间排序，有 780 行涉及重复购买时间戳。

IP 映射先检查区间不重叠，再以 searchsorted 找到不大于 IP 的最大下界并检查上界。20,291 行未覆盖，占 14.66%。138,375 个 IP 值带小数部分，按文件原值匹配；数值编码来源未知。查表结果不证明真实位置。查表版本时间也未知，因此国家只用于描述，不进入模型。

欺诈标签占比

欺诈标签共 1,415 个，非欺诈标签 136,961 个，整体占比 1.02%。全判正常也能取得很高的准确率，因此准确率不用于选模。AP（average 精确率，平均精确率）衡量排序，计算采用召回增量加权的精确率。它不是 PR 曲线的梯形面积；ROC-AUC 作为辅助指标。

交易时间与特征分布

739 笔注册后不超过一秒的交易全部标为欺诈，集中在 2015-01-01 至 2015-01-13，占全体欺诈的 52.23%。之后的前向验证窗口、选择集和测试集均没有这类样本。随机划分把早期模式分配到训练与验证，可能重复识别同一历史结构。

一秒模式消失、购买间隔拉长、先前设备活动占比变化，是可观察的特征分布变化。注册时间在八月截止而购买继续到十二月，也限制了对后期人群的解释。来源、浏览器、年龄与金额按月检查，图中的样本组成变化不等同于机制识别。

人群构成变化、特征分布变化与标签占比变化分别描述不同现象。概念或机制变化涉及特征与标签条件关系变化；本分析没有独立确认该机制，更不能直接推断欺诈者改变了策略。

从审核用途看，极短购买间隔是一个有依据的调查线索。需要同时观察其出现量、欺诈占比与时间分布；早期样本中的强关联不能直接变成长期通用的拒单条件。

打分时点的特征

目标

让特征对应订单提交时已可观察的信息，防止把未来交易量当成历史活动。

特征契约

连续与日历特征为购买间隔的 log1p、金额、年龄、注册小时、购买小时、注册周末标志、购买周末标志。设备和 IP 分别计数严格早于当前购买时间的交易；排除当前行及所有同时发生的记录。性别（sex）、渠道（source）、浏览器（browser） 在每个训练折内拟合独热编码，未知类别忽略。

原始数据表保持不变，特征从副本派生；重复执行不会再次编码性别。用户 ID、原始设备/IP 标识、购买日期、标签、国家和全窗口频次不进入模型。验证和测试期间已发生的无标签事件可以更新更晚交易的计数，模型不重拟合。

代价

计数描述本地抽样文件中可见的交易流，不能补齐生产系统遗漏的历史事件。题目字段是否在提交时及时到达、后来是否修订，均缺少日志验证。未加入静态窗口频次对照，以保持三种不平衡方法使用相同的逐笔特征。

时间角色与前向验证

目标

将时间泛化作为主协议，分开模型参数选择、阈值选择和冻结评价。

时间划分

按购买时间排序，约前 80% 留作早期数据，其内部再按约 80% 划分拟合集与选择集。边界使用整组时间戳，不让同时交易跨角色。实际范围如下。

拟合集内按唯一时间戳做五折扩展窗口验证，验证日期从 2015-03-16 开始。模型及参数按五折 AP 的等权均值选择，平局按固定方法和参数顺序处理。每种方法选定参数后只在拟合集上重拟合，选择集只选阈值。测试集同时评价预先声明的三个冻结比较对象，保持交叉验证选中的模型身份。

代价

独立选择集减少训练量，但使决策选择与最终评价分离。五个时间折不视为独立重复试验，折间范围不是置信区间。数据曾被全量探索；本轮的流程隔离不能恢复研究层面的盲测独立性。

批准与拒绝基线

全批准和全拒绝在选模前定义。情景成本为：漏判欺诈累计“购买金额加 $15”，再加误拒正常交易数乘 $100。正确分类的增量错误成本设为零。这些是沿用的假设值，不是实测欺诈损失或客户终身价值。

选择集全批准成本 $5,166，全拒绝成本 $2,203,600；它含 104 个欺诈和 22,036 个非欺诈标签。没有证据设置最低召回率、人工审核容量或标签成熟天数。未标记任何交易时，精确率按实现约定记零，并同时显示 TP/FP 以说明分母为空。

不平衡处理比较

目标

在相同逐笔特征和时间协议下，判断 SMOTE 是否提供时间泛化增益。

有界比较

比较无重采样、训练折内按类别频数平衡的权重和普通 SMOTE。LightGBM 保持同一模型家族，避免同时扩大算法范围。三者均搜索 200/400 棵树、31/63 个叶子、0.05/0.1 学习率，共八组参数；随机种子 42、数值库四线程，并设置确定性 LightGBM。编码和采样仅拟合训练折。所有比较对象共完成 120 次折内拟合和三次拟合集上的重拟合。

LightGBM 交叉验证 AP 选择集 AP 测试集 AP 测试集 ROC-AUC
无 SMOTE 0.006945 0.010352 0.009879 0.606678
类别权重 0.006991 0.009761 0.010121 0.595995
普通 SMOTE 0.006854 0.009009 0.009025 0.596598

类别权重的平均交叉验证 AP 最高，被预先选为正式模型。无 SMOTE 与类别权重均选 200 棵树、31 个叶子、0.05 学习率；SMOTE 选 200 棵树、63 个叶子、0.05 学习率。SMOTE 的平均交叉验证 AP 比无 SMOTE 低 0.000091，冻结测试集 AP 低 0.000854。本次没有观察到 SMOTE 增益，这不构成所有数据上优劣的结论。

代价

拟合集审计生成 86,200 条合成记录，其中 82.67% 含带小数值的类别指标，46.34% 含带小数值的周末标志。性别的两个独热列分别约 40.02% 为小数值，计数也出现非整数。普通 SMOTE 未缩放的近邻平方距离中，年龄约占 25.60%，金额约占 23.51%；距离受到不同尺度影响。该比较保留这种做法用于审计，不为 SMOTE 单独加入缩放以改变实验问题。未扩展 SMOTENC、ADASYN 或其他模型家族。

选择集决策边界

阈值候选覆盖选择集的每个唯一分数边界，并显式包括全批准与全拒绝。按 score >= threshold 标记时，相邻分数之间的区间 (lower, upper] 产生相同的选择集决策；高于最大分数的所有阈值对应全批准。内部区间若被选中，固定使用上端点。成本平局先选拒绝数量更少的决策，同时保留所有最小成本候选。

类别权重 t > 0.7791207743942467 0 0 5,166

三种方法均选择全批准，每种只有一个最小成本的操作决策。表中区间描述选择集上的等价性，正式冻结为“始终批准”，不是选某个有限阈值到测试集再比较。这样不会把未来超过选择集最大分数的交易意外拒绝。选择集优化后的成本是同批选择结果，不作为独立验证成绩。

在当前费用假设下，引入拒绝没有降低选择集成本。各边界按召回率、精确率、FPR、TP、FP 与成本进行比较，策略在选择集确定后进入测试评价。

这一实验只比较直接批准与拒绝，没有模拟人工审核及其费用。全批准最优说明在当前假设下，直接拦截没有成本优势；是否采用人工审核属于另一个操作设计问题，具体方案见第十二节。

只使用时间协议拟合集，固定已选类别权重模型参数，各取 70,848 行训练、17,712 行留出。随机对照分层抽样，时间对照留出后段。诊断阶段不再选参；继承参数先前已在完整拟合集的前向交叉验证中选择，因此这些诊断留出并不独立于参数选择。

人工审核与三档处理建议

以下是基于行为分析与模型比较提出的实施建议。方案把模型分数用于安排关注顺序，审核人员再结合交易证据判断；分数未经过概率校准，不能直接解释为真实欺诈概率。

人工审核队列

订单提交后记录模型分数、注册到购买间隔、先前设备／IP 活动及已有交易资料。先旁路登记队列，不改变订单状态，检查数据到达、分数分布和记录完整性。进入试行时，在业务确认的审核容量内按分数从高到低安排复核，同分可按订单等待时间排序。极短购买间隔和异常共享活动作为调查线索随订单展示，不单独触发拒绝。

审核人员检查既有订单与支付核验资料、账户活动以及设备／IP 关联，记录处理理由。模型分数用于排序；个案结论由可核实的交易证据补充。设备／IP 共享本身也可能来自正常场景，新增核验只在确有疑点时进行。

三档订单处理

低／中／高表示建议的处理优先级，不表示已校准的概率档位。分界由业务结合选择集分数分布、实际审核容量和误拒承受程度设定，不照搬固定概率值，也不使用当前测试集反调分界。

低风险 分数相对较低，且现有资料未触发额外核验线索 沿用现有常规流程，并保留抽样复核 后续欺诈标签、抽查结果、订单完成情况
中风险 分数处于待审核区间，或存在需要核实的行为线索 进入常规人工审核队列，核对订单及相关活动 审核结论、理由、耗时与用户等待
高风险 较高分数同时伴随可核实的异常线索 优先人工复核；可按现有业务权限暂缓发货，人工确认后决定放行、补充核验或拒绝 最终决定、佐证、订单取消／申诉及后续标签

试行记录与调整

试行前确定分档规则、审核负责人、容量、等待时限和人工处理权限，并记录版本。按日期与行为子群检查审核命中率、欺诈覆盖、正常订单误拦截、审核耗时及订单完成情况，同时保留常规流程中的抽样复核，以便观察队列外的遗漏。

标签确认和修订时间应随处理结果一起记录。若高分队列的命中、等待或误拦截表现不符合业务接受范围，可缩小队列或回到原流程，再用新增记录调整。当前全批准结果仅是既定成本情景的实验结论，不作为业务自动审批指令；审核节省、检出提升和分层收益留待试行测量。

试点数据与经营指标

当前协议采用原始字段副本、严格历史计数、时间主线验证、同协议不平衡方法比较和完整分数边界决策。模型选择、阈值选择、冻结测试集与探索诊断各有独立职责。

试点准备可围绕三类信息展开：一是标签生成、确认、观察期和修订记录；二是首单定义、事件到达时间与完整交易历史；三是欺诈损失、误拒费用、人工审核成本与容量。试点中持续记录用户与设备关联、策略调整和审核结果，用新时间窗评价模型与处理流程。

当前没有适用于上述依赖结构和选择过程的性能区间，所有指标按点估计披露。需要新数据的限制不能用更密集的调参消除。

首单风控发现与实施方向

本项目识别了一个集中的历史欺诈子群：739 笔极短间隔购买占全部欺诈标签的 52.23%，且集中于早期。随机诊断 AP=0.635206，排除该子群后为 0.006314，说明整体随机结果不能代表对其余欺诈的识别能力。子群与时期应成为风控分析的常规比较维度。

同协议比较选出类别权重 LightGBM，普通 SMOTE 没有显示出本次 AP 增益。冻结时间测试集 AP=0.010121，高于该窗口 0.47% 的欺诈占比，但排序仍较弱。既定成本下选出的全批准决策在 27,676 笔测试集交易中未检出 131 个欺诈，情景成本 $6,876。零检出描述的是这一操作决策；它不等于所有分数都没有信息，也不证明人工审核方案有效。

建议优先把模型与行为线索用于辅助人工审核。按相对分数和可核实线索安排低／中／高三档处理，持续记录审核结果、订单影响和标签修订。项目交付包括行为发现、模型比较、决策取舍分析及可供试行的流程建议。

实施准备优先补齐实际审核容量、处理权限、交易核验资料与成本口径；试行中积累新的时间窗和成熟标签，再判断是否调整分档或模型。
